# 💊 Web App Klaim Obat

Aplikasi berbasis web yang dirancang untuk mengelola dan mempermudah proses pengajuan klaim obat karyawan/pasien secara efisien dan terstruktur.

---

## 🚀 Fitur Utama
- **Pengajuan Klaim:** Form pengajuan klaim obat beserta lampiran resep/kuitansi.
- **Verifikasi & Persetujuan:** Sistem persetujuan (*approval*) status klaim oleh Admin/HRD.
- **Manajemen Data:** Pengelolaan data obat, data pengguna, dan histori klaim.
- **Role-Based Access Control (RBAC):** Hak akses terpisah sesuai peran pengguna.

---

## 🛠️ Tech Stack & Modul
- **Framework:** CodeIgniter 4 (PHP)
- **Database:** MySQL
- **Frontend:** Bootstrap / HTML5 / CSS3 / JavaScript
- **Architecture:** Model-View-Controller (MVC)
